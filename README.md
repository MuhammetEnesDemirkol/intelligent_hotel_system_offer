# Intelligent Hotel Management System - Frontend

## About the Project

This project is a user-friendly and powerful frontend application designed for a modern and intelligent hotel management system. Built using React and Vite, it simplifies hotel operations, enhances customer satisfaction, and optimizes management processes.

## Key Features

### User Interface

* **Homepage and Room Listings**: View available rooms and their status.
* **Room Details and Reservations**: Explore room features and make online reservations.
* **User Registration and Login**: Account creation, login, and session management.
* **Account Management**: Update personal information and track reservation history.
* **Secure Payment System**: Perform online transactions securely.

### Admin Panel

* **Dashboard and Reporting**: Real-time hotel performance monitoring through charts and reports.
* **Room Management**: Easily update room status, cleaning, and maintenance details.
* **Customer Management**: View, update, and manage customer communication.
* **Reservation Management**: View, modify, and cancel reservations.
* **Staff Management**: Manage staff details, assign tasks, and track progress.
* **Pricing System**: Adjust room prices based on seasons, demand, and special events.

## Technologies Used

* **React 19**
* **React Router DOM**
* **Vite**
* **Bootstrap 5** (for UI design)
* **Chart.js** (for analytics)
* **Axios** (for API requests and data handling)
* **React Calendar** (for date selection)

## Getting Started

### Installation

1. Clone the repository:

```bash
git clone [repo-url]
cd [repo-directory]
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Build the project for production:

```bash
npm run build
```

### Project Structure

```
src/
├── components/       # Reusable general components
├── layouts/          # Page layouts (main structure)
├── pages/            # Routed page components
├── styles/           # CSS and style files
├── App.jsx           # Main application component
└── main.jsx          # Application entry point
```

## Security Features

* Authorization mechanism for accessing admin panel
* JWT-based user authentication
* Protected routes (PrivateRoute) to prevent unauthorized access
